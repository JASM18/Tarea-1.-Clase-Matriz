Matriz & Matriz::operator= ( const Matriz & m)

Operador de asignación.

Parameters
mMatriz a asignar.
Returns
Referencia a la matriz actual (*this).

Si hay memoria asignada, entonces procedemos a borrarla

Se crea un arreglo dinamico tal que tamaño del arreglo es la cantidad de filas que hay

Se recorre CADA FILA (el i va a recorrer cada fila)

A cada fila le asignamos sus columas. La fila 'i' tendrá 'columnas' espacios para números

Para la fila 'i', vamos a recorrer cada una de sus columnas para asignarle '0'
